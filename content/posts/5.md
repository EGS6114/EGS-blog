## 1.前言

[vercel](https://vercel.com/) 是一个国内**相对较快**，知名度较高的**边缘函数**，本文将讲解**ip优选**，**缓存配置**，**缓存预热**等方法让你的vecel快到起飞

## 2.地区优选

vercel虽然说是有全球的边缘节点，但是边缘函数的运行节点是可选的，具体步骤如下：
1.  进入已部署的项目 → `Settings` → `Functions` → `Functions Region`
2.  默认勾的是 `Washington, D.C., USA (iad1)`，也就是**美国东部**
3. **取消勾选**`Washington, D.C.`，把函数地区改到离你更近的地方，例如亚太地区的香港、日本、新加坡等
4. 注意只能选一个，因为免费计划不支持多地区

## 3.ip优选

#### 为什么需要IP优选？

Vercel的服务器默认在海外（如美国）。为了让你在全球任何地方都能访问，Vercel使用了**Anycast**。简单来说，就是让全球不同位置的服务器共用同一个IP地址，用户的请求会自动被路由到“最近”的服务器。

**这本意是好的，但在实践中却带来了问题：**

- **自动路由不“智能”**：对于中国大陆的用户，这个“最近”的服务器可能被导向了**东南亚或香港的节点**。这些节点因为使用人数多，常常**线路拥堵**，导致延迟非常高。

- **高峰期访问困难**：在晚高峰等时段，丢包和访问超时的情况会更加严重，甚至直接打不开。

- **并非所有节点都慢**：实际上，Vercel在中国大陆周边（如日本、韩国、新加坡等）还有不少速度更快的节点。问题在于，默认的自动路由机制不一定会把你引导到这些更优的节点上。

简单说，**“IP优选”就是主动去寻找并指定一条更快的“VIP通道”，来绕过拥堵的路线**。

#### 什么是ip优选？

“优选”就是**跳过默认解析，手动把域名指向一个实测速度最快的vercel边缘ip**。

#### 如何优选？

常见的优选域名如下：

`cname-china.vercel-dns.com`
`vercel.cdn.yt-blog.top` 等等

直接把cname记录改为其中一个即可（记住要等证书签发之后）

## 3.缓存配置

Vercel官方支持通过 `vercel.json` 文件配置缓存，主要通过为特定路由设置 `Cache-Control` 响应头来实现，如果你是静态博客直接无脑搬就可以：

          "value": "1; mode=block"

        },

          "key": "Referrer-Policy",

          "value": "strict-origin-when-cross-origin"

## 4.缓存预热

新部署的缓存是空的，第一个访问某个页面的人，会命中 `MISS`、回源一次，然后 CDN 才会把页面缓存下来。

我们可以通过github actions工作流自动预热缓存，如下：
```cache.yml
name: Vercel 缓存

  

on:

  push:

    branches: [main]

  workflow_dispatch:  

  

jobs:

  warmup:

    runs-on: ubuntu-latest

    steps:

      - uses: actions/checkout@v4

  

      - name: 等待 Vercel 部署完成

        run: sleep 60

  

      - name: 提取 sitemap

        run: |

          curl -s -m 30 https://yourblog.com/sitemap.xml \

            | grep -oP '(?<=<loc>)[^<]+' \

            | sed 's/\r$//' > urls.txt

          echo "共提取 $(wc -l < urls.txt) 个页面"

  
  

      - name: 预热边缘缓存

        run: |

          cat urls.txt | xargs -P 8 -I {} curl -s -o /dev/null -m 20 "{}" || true

  

      - name: 检查缓存命中率

        run: |

          total=0; hit=0; miss=0

          : > detail.txt

          while IFS= read -r url; do

            [ -z "$url" ] && continue

            total=$((total+1))

            cache=$(curl -s -o /dev/null -m 20 -D - "$url" \

              | grep -i '^x-vercel-cache:' | tr -d '\r' | awk '{print $2}')

            [ -z "$cache" ] && cache="N/A"

            if [ "$cache" = "HIT" ]; then hit=$((hit+1)); else miss=$((miss+1)); fi

            echo "$cache|$url" >> detail.txt

          done < urls.txt

  

          if [ "$total" -gt 0 ]; then

            rate=$(awk "BEGIN{printf \"%.1f\", $hit*100.0/$total}")

          else

            rate="0.0"

          fi

  

          {

            echo "# Vercel 边缘缓存预热报告"

            echo ""

            echo "> 生成时间：$(date -u '+%Y-%m-%d %H:%M:%S UTC')"

            echo ""

            echo "| 指标 | 数值 |"

            echo "|------|------|"

            echo "| 总页面数 | $total |"

            echo "| 命中 HIT | $hit |"

            echo "| 未命中 MISS | $miss |"

            echo "| 命中率 | $rate% |"

            echo ""

            echo "## 详细状态"

            echo ""

            echo "| 状态 | URL |"

            echo "|------|-----|"

            while IFS='|' read -r cache url; do

              echo "| $cache | $url |"

            done < detail.txt

          } > HIT.txt

  

          cat HIT.txt

  

      - name: 上传报告

        uses: actions/upload-artifact@v4

        with:

          name: cache-report

          path: HIT.txt

          retention-days: 7
```

把 `https://yourblog.com/sitemap.xml`改为你的sitemap链接即可，工作流抄自upxuu的[什么？你的vercel还没深绿？一文研究透vercel优选|缓存配置 - UpXuu's blog](https://upxuu.com/posts/vercel-youxuan-cache) 原版在这里[cache-hit-check.yml](https://github.com/ImUpXuu/xuhome/blob/main/.github/workflows/cache-hit-check.yml)
